# Metaphor bank

Pictures already in use. Reuse them so the same concept keeps the same picture across
tutor notes, slides and learner references. Each has been mapped part by part and has a
known break. A project may keep its own copy (the AI Arc repo keeps one in
`docs/teaching-content-style.md`); prefer the project's copy when it exists, and add new
pictures there.

## AI fundamentals

| Concept | Picture | Where it breaks |
|---|---|---|
| AI, ML, deep learning, LLM | Steel dabbas, one inside the other | The fields overlap; dabbas fit perfectly |
| Tokens | Paying cash with a fixed set of notes and coins | A coin has no meaning beyond its value |
| Weights and training | A restaurant perfecting its sambar recipe, printed for every branch | A cook knows what salt does; nobody knows what one weight does |
| Next-token prediction | WhatsApp keyboard suggestions, scaled up | The keyboard sees a few words; the model reads everything |
| Context window | A table cleared after every question | Every paper is re-read and paid for each time |
| Temperature, non-determinism | Two cooks, one sambar recipe | One system with dice, not two people with judgement |
| Hallucination | A stranger giving confident directions in a new town | The stranger may know he is guessing; the AI cannot tell |
| Chat has no memory | A government hospital doctor; you carry your file every visit | The model forgets after every reply, not every visit |
| GPUs and cost | A wedding kitchen: a hundred helpers chopping onions at once | GPUs are far more specialised than helpers |
| Model sizes, open-weight | Auto, cab or flight; a cab per ride or your own car | You only find out which fits by testing |
| System prompt | A shop owner's discount rule for a new salesman | The model needs the brief re-sent every message |

## Agents and tools

| Concept | Picture | Where it breaks |
|---|---|---|
| Agent | An office boy depositing a cheque, finding the branch closed, trying the next | The office boy has common sense |
| Skills | The recipe notebook in a home kitchen | A cook adjusts the recipe; the AI follows it literally |
| Projects | A CA's file for each client | A thick project costs attention; a thick file costs nothing |
| Routines, scheduled tasks | The newspaper at your door by 6 am | A newspaper is checked by professionals; a routine is not |
| Tool calling | A doctor ordering a blood test; the lab runs it | The AI can write a silly slip, so the lab must check |
| MCP | UPI: banks, payment apps, one standard | UPI has a central system; MCP has none |
| Connectors | Adding your bank in GPay from the list, versus typing IFSC | A connector may offer fewer tools than the manual route |
| MCP server under heavy load | IRCTC Tatkal at 10 am | Limits sit at two layers: the server and the API behind it |

## Context and retrieval

| Concept | Picture | Where it breaks |
|---|---|---|
| Context rot | Cramming the whole textbook the night before an exam | A student knows they rushed the middle |
| Context engineering, compaction | Packing to a 15 kg check-in limit; the counter removes things | You notice a missing charger; wrong answers go unnoticed |
| Embeddings | A supermarket shelved by use; sugar-free biscuits next to regular | Hundreds of directions, not a few aisles |
| Chunking | Cutting a cricket match into highlight clips | Many documents have no clear overs |
| RAG | An open-book exam | Basic RAG opens the book every time, even on the wrong page |
| Reranking, hybrid search | Campus placement shortlisting | A reranker does not learn from bad picks |

## Working safely

| Concept | Picture | Where it breaks |
|---|---|---|
| CLAUDE.md, project rules file | The rules notice in a PG hostel | The AI cannot ask the warden what a rule means |
| Hooks | A "No Entry" board against a metro gate | A badly written hook blocks good work too |
| Plan mode, subagents, permissions | Getting a house built: drawing first, separate inspector, keys per worker | A subagent starts completely blank |

## Adding a picture

A new picture earns a row when it maps every moving part of the concept in a table, and
its break is known and stated.
